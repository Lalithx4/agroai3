- (insight) The winning shape is ONE feature: 'Your plant calls you back'. Scan -> a few seconds later an incoming-call screen rings ('Tomato, east field, calling') -> hands-free voice conversation reusing the existing PlantVoice loop -> call log + SMS-style summary + follow-up photo request. Role-play ideas (follow-up, recovery check) give it purpose; what-if ideas (plant as caller, memory, mood voice) give it soul; reverse-brainstorm safeguards (opt-in, quiet hours, confidence guard on calls) make it credible.
- (insight) Build in two phases. Phase 1 (hackathon, no telephony account): in-app incoming-call UI + ringtone + vibration + background Notification, triggered by 'Call me in 30 s' on the report and by a rules trigger engine; conversation runs on Sarvam STT/TTS + Bedrock/Sarvam chat already in the code. Phase 2 (after): real PSTN calls via Exotel (India) or Twilio with streaming audio to Sarvam, which also reaches feature-phone farmers - the inclusion story for judges.
- (insight) Hidden link: the 'judges think it is pre-recorded' failure is solved by the live-language idea - let a judge pick Telugu/Hindi and ask anything mid-call; and the 'feels robotic' latency risk is solved by streaming TTS plus barge-in, which also delivers the 'talks like a person' ask from the user.
- (decision) Recommended next build: Phase 1 'Plant calls you back' (incoming-call screen, call conversation, call log, follow-up reminder) inside CropMagix; Phase 2 Exotel/Twilio real calls documented as roadmap.
